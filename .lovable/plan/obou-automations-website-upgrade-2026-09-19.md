# OBOU Automations Website Upgrade

## Goal
Build a production-quality multi-page website that feels unmistakably like the current OBOU brand, while making its practical AI systems easier to understand, explore, and act on.

## Brand system to preserve
- Warm paper ground `#f9f4eb`, near-black ink `#111113`, coral signal accent `#fc5957`, acid-yellow structural highlight `#e3f42a`, plus the current warm neutral ramp.
- Current modernist/Swiss character: large compact display type, readable body copy, uppercase mono-style labels, strong rules, square corners, and restrained density.
- Current Archivo variable font files as the available licensed-safe fallback for the live site's PP Rader / PP Neue Montreal / Sligoil Micro stacks.
- Existing red OBOU character mark and wordmark treatment.
- Flat ruled layouts rather than rounded SaaS cards, with motion derived only from the existing coral/yellow/ink palette.

## Build
### Shared site foundation
- Create a reusable header, mobile navigation, footer, CTA system, section introductions, workflow diagrams, and structured content blocks.
- Expand the design tokens in the global stylesheet and copy the current OBOU logo/font assets into the project.
- Add subtle flow, state-change, reveal, and pointer motion with a reduced-motion fallback.
- Keep sections editorial and spacious, occasionally breaking the grid without sacrificing readability.

### Homepage `/`
- Build the complete story from repetitive work to one installed workflow and measured expansion.
- Add the animated integrated workflow field in the opening section.
- Build the four solution categories with distinctive workflow visuals.
- Add the interactive Today / With OBOU comparison.
- Add AI Quick Wins, the visual Opportunity Audit report, three engagement paths, four-step process, and human-in-the-loop philosophy.
- Add the frontend-only Automation Opportunity Finder with questionnaire, mock recommendations, time-saved estimate, and contact capture.

### Supporting routes
- `/solutions`: deeper sales, operations, marketing, and knowledge systems with outcome-first diagrams.
- `/how-to-start`: audit, quick win, complete system, process, expectations, and next-step CTA.
- `/work`: clearly labelled “Example system” demonstrations only; no invented clients, testimonials, logos, or claims.
- `/tools`: product-like tool library with the Opportunity Finder live and four coming-soon tools.
- `/about`: OBOU philosophy, practical implementation approach, and human/AI responsibilities.
- `/contact`: concise opportunity intake that directs visitors to the existing OBOU booking link.

## Interaction and content
- Use plain business language and concrete examples; keep technical implementation terms out of the primary story.
- Make diagrams readable on mobile by reducing stages and using horizontal/vertical state sequences appropriately.
- Keep all forms as polished frontend demos for now, with clear seams for later AI, email, CRM, calendar, and analytics integrations.
- Use the current Google Calendar booking destination already published by OBOU.

## Quality checks
- Add unique metadata to every page, semantic headings, accessible labels, keyboard navigation, visible focus states, and structured organization/service data.
- Verify every route at desktop and mobile sizes, including the navigation, workflow toggle, opportunity finder, and all CTA destinations.
- Confirm the final visuals use only the extracted OBOU palette and do not drift into generic AI styling.
